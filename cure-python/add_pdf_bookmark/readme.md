# 项目说明

本项是为了快速给 PDF 添加书签。

平时下载的一些 PDF 没有书签，不方便阅读，所以想着写一个程序来快速完成添加书签的操作。当然现在也有一些软件可以做到，不过就当是熟悉 python 啦。



## 用法说明

### 确定目录文件以及它的格式

首先目录的格式预定义如下（从豆瓣复制目录就是这种格式，但可以根据不同格式对代码进行调整）

```python
第x章 name 1    # 当然，还有直接 `12 name 100` 这样表示第 12 章，标题为 name，在第 100 页

1.1 name 13

1.2 name 23
```



如上，最前面的是章节号、小节号等，一个或多个空格之后就是标签名 xxx，最后的一个空格后，就是页数。



### 确定页偏移

1. 先查看目录文件（后面称之为 cat 文件），**假设第一项只给出了：第一章 xxxxx 1，说明第一章的封面为第 1 页**。
2. PDF 中找到对应的第一章封面，页数为 13（是看 PDF 编辑器下面显示的页数哟）。
3. 那么页偏移为 13 - 1 = 12。那么现在对于 cat 文件中的任意一个小节 `xxxxx a`（a 表示目录文件 cat 中某个小节的页数），则对应 PDF 中的 12 + a 页，由于编程时从 0 开始数，所以要记住，最终插入标签到某一页时，页数要 -1。
4. 对于 PDF 中的任意一页的页数 b，则对应 cat 文件中的 b - 12 = a，这样可以自己添加目录项了

举例：

比如 PDF 中目录页所在的页数为 9，那么可以在 cat 文件中添加一条: `目录 -3`（即 9 - 12 的结果，这里的 12 就是页偏移），这样，最后就能生成了目录的标签。
